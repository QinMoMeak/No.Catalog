# NoCatalog 实施计划

本文档使用 UTF-8 编码维护，记录当前阶段的交付边界和推进顺序。

## 阶段拆分

1. 阶段一：初始化 Android 工程骨架
   - 完成 Gradle、Compose、Hilt、Room、DataStore、Navigation 基础配置
   - 建立分层目录、核心模型和页面骨架
   - 建立工作日志
2. 阶段二：打通本地数据闭环
   - 完成 Room 实体、DAO、Repository
   - 完成首页、详情、编辑基本流程
3. 阶段三：完成导入导出
   - 完成 CSV 导入导出
   - 完成 JSON 备份格式读写
   - 完成导入预览和冲突确认
4. 阶段四：完成密码锁
   - 完成密码设置、校验、解锁态管理
   - 完成冷启动与超时重新解锁流程
5. 阶段五：完成 WebDAV 手动备份恢复
   - 完成配置保存、连接测试、备份上传、远端恢复

## 当前阶段

阶段一到阶段五的 V1 主功能已全部落地，并通过本机构建验证。

当前已经产出可使用的完整 debug APK。后续工作主要聚焦测试覆盖、兼容性优化和体验打磨。
