# 给 Codex 的 UI 重构指令

请在**不改动现有业务功能和数据逻辑**的前提下，重构 Android App 的 UI，使其符合 **Material Design 3** 风格，重点提升视觉层级、间距、统一性和可读性。

## 总体要求

1. 使用 **Jetpack Compose Material 3** 组件重构现有界面。
2. 不要改动已有功能流程，只做 UI 和交互层优化。
3. 保持当前产品的柔和风格：
   - 页面背景：淡粉色 / 米色系浅色背景
   - 主强调色：淡紫色 / 紫色
   - 文本主色：深灰 / 蓝灰
   - 避免大面积厚重深色按钮
4. 全局统一：
   - 圆角：卡片和按钮统一使用 16dp ~ 24dp
   - 页面横向边距：16dp
   - 模块间距：12dp ~ 16dp
   - 卡片内边距：12dp ~ 16dp
   - 图标和文本对齐，避免拥挤
5. 所有页面都要建立清晰的视觉层级：
   - 顶部 AppBar
   - 内容区按卡片分组
   - 底部导航栏仅保留一级页面
6. 优先重构：
   - 首页
   - 统计页
   - 设置页
   - 全局主题 / 组件样式

------

## 一、全局主题重构

请新增或整理以下内容：

### 1. App Theme

- 建立统一的 Material 3 Theme
- 自定义 `ColorScheme`
- 定义：
  - `primary`: 淡紫色
  - `secondary`: 柔和粉紫
  - `background`: 浅米色 / 浅粉色
  - `surface`: 白色或微暖白
  - `onSurface`: 深灰色
- 保证卡片、按钮、输入框、导航栏的颜色统一

### 2. Typography

- 使用 Material 3 typography
- 标题、正文、说明文字分级明确：
  - 页面标题：`headlineSmall`
  - 卡片标题：`titleMedium`
  - 正文：`bodyMedium`
  - 辅助说明：`bodySmall`

### 3. 通用组件样式

请抽出统一组件或样式封装：

- `AppTopBar`
- `SectionCard`
- `EmptyCoverPlaceholder`
- `StatCard`
- `FilterChipGroup`
- `SettingGroupCard`

------

## 二、底部导航结构

底部导航保持三大块：

- 首页
- 统计
- 设置

要求：

1. 使用 `NavigationBar`
2. 选中项使用淡紫色强调
3. 图标和文字统一居中
4. 一级页面显示底部栏
5. 二级页面隐藏底部栏：
   - 详情页
   - 编辑页
   - 导入导出页
   - 备份页
   - 导入预览页

------

## 三、首页重构

首页要从“功能堆砌”改成“分层明确的管理页”。

### 1. 顶部 AppBar

请把首页顶部整理为标准 Material 3 TopAppBar：

左侧：

- 应用标题：`NoCatalog`

右侧图标区：

- 搜索按钮
- 导入导出按钮
- 备份或更多操作按钮

不要再把功能按钮零散堆在正文区域。

### 2. 搜索

- 点击搜索图标后展开搜索框，或在 AppBar 下显示一个紧凑搜索框
- 搜索框圆角统一，使用 Material 3 `SearchBar` 或 `OutlinedTextField`
- 占位文字清晰，例如：`搜索番号、标题、演员`

### 3. 筛选和排序区域

在 AppBar 下方新增一个独立的“筛选控制卡片”，不要让筛选项散乱分布。

包含：

- 视图切换：卡片 / 表格
- 排序方式
- 已看 / 未看
- 星标
- 标签筛选入口
- 演员筛选入口

要求：

- 使用 `SegmentedButtonRow`、`FilterChip`、`AssistChip`、`ExposedDropdownMenuBox`
- 标签筛选和演员筛选可以点击进入底部弹窗或选择对话框
- 移除右侧垂直按钮，彻底取消这种布局

### 4. 列表卡片重构

首页卡片必须统一。

每个卡片结构：

左侧：

- 固定比例封面图
- 建议比例 2:3
- 宽度约 72dp ~ 84dp
- 无封面时显示统一占位图，不要每条样式不同

右侧内容区：

- 第一行：番号
- 第二行：标题
- 第三行：演员
- 第四行：日期 / 标签摘要 / 状态

右下角：

- 星形图标 + 评分数字，例如 `⭐ 3.5`

要求：

- 卡片高度统一
- 标题最多 2 行，超出省略
- 演员最多 1 行或 2 行，超出省略
- 左右对齐整齐
- 不要出现过密的文本堆叠

### 5. FAB

- 保留右下角新增按钮
- 使用淡紫色主按钮
- 图标清晰
- 与底部导航和内容保持安全间距

------

## 四、统计页重构

统计页要从“数据罗列”改成“概览 + 分组展示”。

### 1. 页面结构

从上到下建议为：

1. 页面标题
2. 核心数据概览卡片区
3. 状态统计卡片
4. Top 标签卡片
5. Top 演员卡片

### 2. 核心统计区

使用 2x2 网格卡片展示：

- 总记录数
- 已看
- 未看
- 星标

每个卡片包含：

- 图标
- 标题
- 大数字
- 辅助说明文字（可选）

要求：

- 数字明显放大
- 图标颜色柔和但可识别
- 卡片统一高度

### 3. 状态统计

状态统计卡片中每个状态使用：

- 状态名称
- 数量
- 百分比
- 进度条

要求：

- 文本在上
- 进度条在下
- 对齐整齐
- 百分比可读

### 4. Top 标签 / Top 演员

分别做成独立卡片。

每个列表项建议：

- 左侧图标
- 中间名称
- 右侧数量徽标或数字

要求：

- 名称和数量对齐
- 行高统一
- 不要只是裸文本列表

------

## 五、设置页重构

设置页不要改成传统 PreferenceScreen，继续使用 Compose Material 3，但要做成“设置分组卡片”。

### 页面结构建议

1. 顶部 AppBar
2. “显示设置”分组
3. “安全设置”分组
4. “数据与备份”分组
5. “关于”分组（如已有）

### 1. 显示设置

包括：

- 首页视图
- 默认排序

推荐组件：

- `SingleChoiceSegmentedButtonRow`
- 或 `ExposedDropdownMenuBox`

### 2. 安全设置

包括：

- 密码锁开关
- 更改密码
- 关闭密码锁

要求：

- “密码锁”用带说明文字的 `Switch` 行
- “更改密码”点开对话框
- 密码输入框使用现代 Material 3 文本框
- 不要堆多个厚重按钮

### 3. 数据与备份

包括：

- 导入导出入口
- WebDAV 备份入口

使用带图标的设置项卡片行：

- 左图标
- 中标题 + 副标题
- 右箭头

### 4. 返回按钮

如果已经有 AppBar 返回箭头，就不要在页面底部再放“返回”按钮。

------

## 六、编辑页和详情页补充优化

### 编辑页

- 使用分组表单
- 基础信息、演员标签、评分备注、封面与来源分成多个 section
- 输入框统一圆角和高度
- 本地封面选择区域做成卡片式预览，不要只是一个普通按钮

### 详情页

- 顶部展示大封面 + 基本信息
- 下方分组展示演员、标签、备注、状态
- 操作按钮使用图标按钮或轻量按钮，不要一排压迫感很强的大按钮

------

## 七、实现限制

1. 不要改动数据库结构和业务逻辑
2. 不要移除现有功能
3. 优先优化以下内容：
   - 间距
   - 卡片统一
   - 信息层级
   - 顶栏 / 底栏结构
   - Material 3 组件替换
4. 不要过度炫技，不引入复杂动画
5. 保持可运行，最后确保 `assembleDebug` 通过

------

## 八、交付顺序

请按以下顺序修改：

1. 全局 Theme / ColorScheme / Typography
2. 底部导航和顶栏统一
3. 首页重构
4. 统计页重构
5. 设置页重构
6. 编辑页 / 详情页局部美化
7. 自检并保证可编译运行

------
